# Relics of Cthonia 2.0.1 — Slimefun Legacy

Relics of Cthonia 2.0.1 is a compatibility and stability maintenance release for modern **Slimefun Legacy** servers while preserving the original addon gameplay, relic progression, item IDs, recipes, drop rates, and Piglin reward configuration.

## Platform

- Production baseline: **Paper 26.2**.
- Built with **Java 25** while emitting **Java 21 bytecode**.
- Tested at runtime with the latest Slimefun Legacy release.
- Includes embedded Slimefun Legacy compatibility metadata so current Legacy diagnostics classify the addon as **Compatible**.

## Compatibility and stability

- Updated the max-health attribute usage to the modern Paper API.
- Corrected off-hand relic interaction handling.
- Stopped random relic selection from shuffling shared registry lists in place.
- Persisted spawner-origin mob markers through Bukkit PDC.
- Migrated relic condition and voider quota storage to Bukkit PDC while retaining the existing namespaced keys.
- Hardened temporary Piglin barter cleanup for completed, cancelled, and interrupted trades.
- Made the Piglin reward handoff map safe for concurrent access.
- Corrected Eye of Sauron reporting so it identifies the detected player rather than the scanning player.

## Preserved compatibility

The following remain intentionally unchanged:

- Slimefun item IDs;
- recipes;
- relic items and textures;
- rarity tiers and drop chances;
- Piglin reward tables;
- existing configuration keys and `relic-settings.yml` behavior;
- existing relic condition and voider quota persistent-data keys.

## Release asset

The maintained Slimefun Legacy-style release asset is the raw, uncompressed JAR:

`SF_RelicsOfCthonia2.0.1.jar`

No ZIP wrapper is required for normal plugin installation.
