# Relics of Cthonia 2.0.2 — Paper 1.21.11 Compatibility

Relics of Cthonia 2.0.2 broadens the maintained Slimefun Legacy build so the same addon JAR can run on older Paper 1.21.11 servers as well as current Paper 26.2 servers.

## Compatibility

- Lowered the Bukkit/Paper plugin API declaration from `26.2` to `1.21.11`.
- Compiles against the Paper `1.21.11-R0.1-SNAPSHOT` API baseline to catch accidental use of APIs that exist only in newer Paper releases.
- Continues to emit Java 21 bytecode while CI builds with Java 25.
- Updated Slimefun Legacy compatibility metadata so 1.21.11 is recognized as the minimum supported Minecraft/Paper baseline.
- Added runtime smoke tests for both Paper 1.21.11 and Paper 26.2 before a release can be published.

## Gameplay and data

No gameplay balance, relic IDs, recipes, drop rates, Piglin barter rewards, configuration keys, or persisted relic data formats are intentionally changed by this release.

## Server owners

Replace the previous Relics of Cthonia JAR with `SF_RelicsOfCthonia2.0.2.jar` while the server is fully stopped. Do not use plugin hot-reload tools when replacing Slimefun addons.
